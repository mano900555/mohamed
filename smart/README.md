# Smart Teacher - نظام إدارة المدرس v2.0

نظام إدارة متكامل للمدرسين، مصمم لمدرس واحد يدير مئات أو آلاف الطلاب.

## 🚀 المميزات الكاملة

### ✅ الأساسية
- **تسجيل دخول** — نظام Auth كامل (Supabase Auth)
- **Dashboard** — إحصائيات + حصص اليوم + تنبيهات المخاطر
- **الطلاب** — إضافة/حذف/بحث/ملف كامل 360°
- **المجموعات** — إنشاء مجموعات مع أيام وأوقات
- **الحضور** — تسجيل حضور يدوي بأزرار ملونة

### ✅ التعليم
- **المحتوى التعليمي** — PDF، فيديوهات، روابط
- **الواجبات** — إنشاء وتوزيع واجبات
- **الاختبارات** — إنشاء اختبارات + إدخال درجات لكل طالب

### ✅ المالية
- **المدفوعات** — خزنة + إيرادات + مصروفات + عمليات
- **التقارير** — إحصائيات شاملة (طلاب + حضور + درجات + مالية)

### ✅ التشغيل
- **الحصة** — بدء الحصة → تسجيل الحضور → إنهاء → استخراج الغائبين
- **رسائل WhatsApp** — إعداد رسائل الغياب جاهزة للنسخ
- **اكتشاف المخاطر** — طلاب يحتاجون متابعة (غياب + درجات منخفضة)
- **سجل العمليات** — تتبع كل التغييرات (Audit Log)

### ✅ الأدوات
- **ولي الأمر** — بوابة منفصلة (بدون تسجيل دخول)
- **استيراد/تصدير CSV** — طلاب + حضور + مدفوعات
- **إعدادات النظام** — اسم المدرس + المركز + قيم الاشتراك + حدود التنبيه
- **Quick Actions** — زر عائم للعمليات السريعة

## 📦 التقنيات

- Next.js 14 (Static Export)
- React 18 + TypeScript
- Tailwind CSS
- Supabase (Auth + PostgreSQL + Storage)
- Lucide Icons

## ⚙️ خطوات التشغيل

### 1. إعداد Supabase

1. افتح [supabase.com](https://supabase.com) وسجل حساب
2. اعمل New Project
3. اذهب إلى **Authentication** → **Providers** → **Email** → فعله
4. اذهب إلى **SQL Editor** → **New query**
5. افتح ملف `supabase-setup.sql` وانسخه والصقه ثم اضغط **Run**
6. اذهب إلى **Project Settings** → **API** → انسخ `Project URL` و `anon public`

### 2. تشغيل محلياً

```bash
# 1. املأ ملف .env.local
NEXT_PUBLIC_SUPABASE_URL=https://xxxxxxxx.supabase.co
NEXT_PUBLIC_SUPABASE_ANON_KEY=eyJ...

# 2. ثبت الحزم
npm install

# 3. شغل المشروع
npm run dev

# 4. افتح
http://localhost:3000
```

### 3. رفع على Vercel

```bash
# 1. اعمل حساب على vercel.com
# 2. اربطه بـ GitHub أو ارفع الملفات
# 3. أضف متغيرات البيئة:
#    NEXT_PUBLIC_SUPABASE_URL
#    NEXT_PUBLIC_SUPABASE_ANON_KEY
# 4. Deploy
```

## 💡 ملاحظات

1. **النظام لمدرس واحد** — لا يوجد RBAC معقد
2. **Supabase Free** — يكفي لـ 300-500 طالب، ثم ارفع لـ Pro
3. **WhatsApp** — الرسائل جاهزة للنسخ/لصق (بدون API رسمي)
4. **Audit Log** — يسجل الإضافات والحذف والمدفوعات
5. **Risk Detection** — يكتشف الطلاب ذوي الغياب المتكرر أو الدرجات المنخفضة
6. **Parent Portal** — يعمل بدون تسجيل دخول (تبحث برقم Center ID)

## 🔐 الأمان

- تسجيل دخول بـ Supabase Auth
- RLS (Row Level Security) مفعل على كل الجداول
- حماية الصفحات: غير المسجلين يُحوّلون لصفحة الدخول
